# Personal Portfolio Website

A modern and responsive personal portfolio website built with ReactJS and Vite. This website showcases my skills, projects, background, and contact information in an organized and interactive interface.

## Overview

This portfolio website acts as a digital resume and project showcase. It provides visitors with information about my technical skills, experience, completed projects, and professional interests.

The frontend was developed using ReactJS with reusable components, organized pages, custom styling, and React libraries to create a responsive and user-friendly experience.

## Folder Description

### `public`

Contains static files that can be accessed directly by the application.

### `src/assets`

Contains images, icons, illustrations, fonts, and other assets used in the portfolio.

### `src/components`

Contains reusable React components used throughout the application.

Examples may include:

- Navbar
- Footer
- Project cards
- Skill cards
- Buttons
- Section components

### `src/Layout`

Contains layout-related components that control the general structure of the website.

### `src/lib`

Contains helper functions, utility files, configuration, or reusable logic.

### `src/Pages`

Contains separate page-level components or main sections of the portfolio.

Examples may include:

- Home
- About
- Projects
- Skills
- Contact

### `src/UI`

Contains reusable user interface elements such as buttons, cards, inputs, dialogs, and other visual components.

### `App.jsx`

The main React application component that combines the different pages and components.

### `App.css`

Contains styles specifically related to the main application component.

### `index.css`

Contains global styles applied throughout the application.

### `main.jsx`

The entry point of the React application. It renders the main application into the HTML root element.

### `vite.config.js`

Contains the Vite configuration used for development and production builds.

### `package.json`

Contains project metadata, dependencies, and scripts used to run, build, and manage the application.

## Getting Started

### Prerequisites

Make sure the following tools are installed:

- Node.js
- npm
- Git

Check the installed versions using:

```bash
node -v
npm -v
git --version
```

### Clone the Repository

```bash
git clone [https://github.com/your-username/portfolio_webiste.git](https://github.com/your-username/portfolio_webiste.git)
```

Replace `your-username` with your GitHub username.

### Navigate to the Project Directory

```bash
cd portfolio_webiste
```

### Install Dependencies

Using npm:

```bash
npm install
```

If you use Bun:

```bash
bun install
```

### Start the Development Server

Using npm:

```bash
npm run dev
```

Using Bun:

```bash
bun run dev
```

After the development server starts, open the local URL displayed in the terminal. Vite commonly uses:

```text
http://localhost:5173
```

## Customization

To customize the portfolio:

1. Update personal information in the appropriate components.
2. Replace images inside the `src/assets` folder.
3. Add your own projects to the Projects section.
4. Update GitHub, LinkedIn, email, and social media links.
5. Add your resume or CV if required.
6. Update colors, fonts, and other styles in `App.css` and `index.css`.
7. Replace the live demo URL in this README.
8. Update the project title and metadata in `index.html`.
